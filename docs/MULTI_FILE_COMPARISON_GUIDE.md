# 📊 多文件对比功能使用指南

## 🎯 功能概述

多文件对比功能允许你同时上传 **2-3个Excel或CSV文件**，进行并排对比分析。

### 典型使用场景

| 场景 | 示例 |
|------|------|
| **月度对比** | 11月.xlsx vs 12月.xlsx vs 1月.xlsx |
| **门店对比** | 门店A.xlsx vs 门店B.xlsx vs 门店C.xlsx |
| **年度对比** | 2023.xlsx vs 2024.xlsx |
| **产品线对比** | 电子产品.xlsx vs 服装.xlsx vs 家居.xlsx |

---

## 🚀 快速开始

### 步骤1：选择上传模式

1. 打开应用：`streamlit run app.py`
2. 在左侧边栏找到 **"上传模式"** 单选按钮
3. 选择 **"📊 多文件对比 (2-3个文件)"**

### 步骤2：上传文件

1. 点击 **"Browse files"** 按钮
2. **同时选择 2-3个文件**（按住 Ctrl/Cmd 多选）
3. 支持格式：`.xlsx` 或 `.csv`

⚠️ **注意**：必须上传 2-3 个文件，否则会显示警告。

### 步骤3：设置文件标签

上传成功后，系统会自动显示 **"📝 为文件设置标签"** 区域：

- **默认标签**：自动从文件名提取（去除扩展名）
- **自定义标签**：可手动修改，最多20个字符
- **示例标签**：`11月`、`12月`、`门店A`、`2023年`

### 3. 📊 并排对比图表

#### 3.1 销售额、订单量、平均订单对比

- **类型**：分组柱状图
- **显示**：3个指标并排对比
- **颜色**：每个文件用不同颜色区分
- **交互**：鼠标悬停查看详细数值

#### 3.2 Top 5 产品销量对比

- **类型**：分组柱状图
- **显示**：各文件的Top 5产品并排对比
- **功能**：快速看出哪些产品在不同时期/门店表现最好

#### 3.3 每日销售趋势对比

- **类型**：多线折线图
- **显示**：各文件的每日销售趋势在同一图表
- **功能**：
  - 对比销售波动模式
  - 查看增长趋势
  - 识别特殊日期（促销、节假日）

### 4. 📅 数据范围信息

显示每个文件的：
- **开始日期**
- **结束日期**
- **总天数**

## 💡 使用技巧

### 1. 文件命名建议

**推荐命名格式**：
- 时间维度：`2024-01.xlsx`、`2024-02.xlsx`
- 门店维度：`StoreA.xlsx`、`StoreB.xlsx`
- 产品线：`Electronics.xlsx`、`Clothing.xlsx`

**不推荐**：
- ❌ `数据(1).xlsx`、`数据(2).xlsx`（无意义）
- ❌ `最新销售数据-修改版-最终版.xlsx`（太长）

### 2. 确保数据格式一致

所有上传的文件必须包含相同的列：
```
✅ 必需列：
- Date（日期）
- Order ID（订单ID）
- Product Name（产品名）
- Quantity（数量）
- Price（价格）
- Customer State（客户州）
- Total（总额）
```

### 3. 时间范围建议

| 对比类型 | 建议天数 | 最佳实践 |
|---------|---------|---------|
| **周对比** | 各7天 | 本周vs上周 |
| **月对比** | 各30天 | 本月vs上月 |
| **季度对比** | 各90天 | 本季vs上季 |

### 4. 数据量建议

- **每个文件**：50-1000条记录最佳
- **总计**：<3000条记录（避免卡顿）
- **超过3000条**：考虑使用数据筛选

## ⚠️ 常见问题

### Q1: 上传2个文件后，为什么看不到对比界面？

**可能原因**：
1. 未选择"多文件对比"模式
2. 文件格式不正确
3. 文件列结构不一致

**解决方法**：
1. 确认已选择 **"📊 多文件对比"** 模式
2. 检查文件是否为 `.xlsx` 或 `.csv`
3. 确保所有文件包含相同的列

### Q2: 为什么只能上传2-3个文件？

**设计考虑**：
- 超过3个文件，图表会过于拥挤
- 对比指标卡片难以并排显示
- 如需对比更多文件，建议分批对比

### Q3: 可以对比不同行业的数据吗？

**可以**，但建议：
- 确保数据格式一致
- 标签起有意义的名称
- 注意单位和币种一致性

### Q4: 对比结果可以导出吗？

**当前版本**：仅支持单文件导出

**未来计划**：
- [ ] 导出对比报告（PDF）
- [ ] 导出对比图表（PNG）
- [ ] 导出增长分析表格（Excel）

## 🎨 示例演示

### 示例1：月度销售对比

**文件准备**：
```
sample_data/
├── 1105-1201.xlsx  (11月数据)
├── 1202-1208.xlsx  (12月数据)
└── nov18-24.xlsx   (11月下旬数据)
```

**标签设置**：
- 文件1：`11月上`
- 文件2：`12月上`
- 文件3：`11月下`

**对比结果**：
- 销售额对比：12月上 > 11月下 > 11月上
- 增长趋势：12月显著增长
- Top产品：查看哪些产品在12月表现更好

### 示例2：门店ABC对比

**假设数据**：
- StoreA: 100笔订单，平均$150
- StoreB: 150笔订单，平均$120
- StoreC: 80笔订单，平均$200

**对比结论**：
- StoreB订单量最高（薄利多销）
- StoreC客单价最高（高端客户）
- StoreA表现平衡
